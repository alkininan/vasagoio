# vasagoio implementation contract

Original addon; no vendor code/assets copied. Public repository contains only this directory. Do not include private project evidence, WTF, account names, chat/inventory/raid data or downloaded fonts.

Every Lua file receives `local addonName, V = ...`. Core defines these APIs before module files load:

- `V:RegisterModule(id, spec)`: spec contains label, description, defaultEnabled, Apply(self), optional Disable(self). `self` is the spec and `V` is captured from the namespace. Apply must be repeat-safe and out of combat. Return `true, detail` for applied; `false, reason` for unavailable/unsupported. Core stores status and catches errors.
- `V:On(event, fn)`: callback receives event and event arguments. Multiple listeners supported. `V:Refresh(reason, moduleId)` coalesces and schedules only that module out of combat; omit moduleId only for explicit global setup/manual/display refresh. Reentrant callbacks receive one bounded follow-up.
- `V:Report(id, state, detail)`: record concise status; states applied, pending, unsupported, disabled, error. Do not log personal data.
- `V:Print(text)`: user-facing chat message.
- `V:SafeNumber(value)`: returns an ordinary number only if not a secret value; never compare/stringify restricted values first.
- `V:IsSecret(value)`: wraps the client's available secret-value predicate conservatively.
- `V:Pixel(n)`: convert reference design pixels to UIParent logical units using uniform 2560x1440 fit and configured layout scale. Never call SetScale on UIParent.
- `V:Font(role)`: returns path, size in logical units, flags. Roles name, amount, compact, heading, title, body, chat, hotkey, count, countdown, compactCountdown, aura. Native fonts only; no redistributed font binaries. Exact Arial Narrow Bold is unresolved unless client/owner exposes a genuine face; do not simulate bold with OUTLINE.
- `V:StyleText(fontString, role, color)`: apply font, color and soft shadow without boxes/outlines.
- `V:Surface(frame, alpha, radius, color)`: original decorative background only, round corners where supported, no bounds changes to existing native controls. Returns a surface frame; repeated calls update. Its child frame and regions are excluded from native layout measurement. Every new decoration must also use `ignoreInLayout` and the owner's `MarkIgnoreInLayout` helper when available.
- `V:HideArtwork(texture)`: root-managed reversible cosmetic hide, without removing gameplay content.
- `V:RegisterProfileAdapter(id, spec)`: label, addon folder, optional module ID, Prepare(self) returns plan {changes={{table=target,path={"SavedVariableGlobal","nestedTable"},key=key,value=value,label=label},...}, detail=string} or nil,reason; optional AfterApply(self). The path resolves the table; key is separate. Setup validates all plans first, snapshots before writing, applies only on explicit user action out of combat. Disabled modules are excluded. Profiles are not silently reset on login. No vendor-private functions without documented/public contract; native SavedVariables schema changes may be targeted only after exact schema checks.

Runtime state: `V.db` is the addon-owned SavedVariables after ADDON_LOADED. `V.db.enabled`, `.modules[id]`, `.overrides`, `.schemaVersion`, `.presetRevision`, `.profileBackups`. First login defaults cosmetic modules on; profile writes require explicit `/vasagoio setup` review/apply. Addon can be unchecked in WoW's AddOns screen. `/vasagoio off` records disabled and requires reload to fully restore hooks/art; profile rollback is separate.

Root owns Core.lua, Tokens.lua, core/*, TOC, README, source manifest, release workflow and package script. Agents own assigned modules and module tests only. Coordinate API changes with root. All functions must guard absent owners and load-on-demand windows, avoid changing protected frames in combat, preserve original native screen structures and selected addon features. Do not launch WoW/CurseForge or write live addon files.

Profile adapters with owner-saved live anchors may implement `ValidateRestore(self, changes)` (pure preflight, returns true or false/reason) and `AfterRestore(self, changes)` (synchronize restored live anchors). Only the adapter's own snapshot entries are passed. That optional changes argument must respect inactive profiles. An initial AfterApply failure rolls saved values back, reconciles live anchors through AfterRestore, removes the failed snapshot and preserves the earlier applied revision; it is not reported as a successful setup. RestedXP captures every live anchor before any move and restores touched frames if any write fails. Do not move guide frames before explicit setup or resize their contents.

## Scoped window interiors

`core/Interiors.lua` provides `V.InteriorSkin` after media and before native/addon adapters. Pass the owning module ID (`nativeWindows` or `addonWindows`) to each mutation; overlapping native and addon scopes share claims. Disabling one owner must not restore an object that another enabled owner still styles. Hooks cannot be removed; they become inert when no owner is active, and complete recovery still requires reload.

- `Apply(root, opts)` traverses only an explicitly registered host's descendants, with a node/depth budget. Options include `owner`, relative `art`/`panels` paths, a `skip` object set, exact `decorativeAtlases`, `maxNodes`, optional `onFrame(frame)`, and an opt-in reviewed Skinner bridge. It reports nodes, controls, texts, panels, skipped/deferred work and budget exhaustion. Callback failures are isolated. Do not enumerate all global frames to discover candidates.
- `Panel(frame, kind, owner)` adds a decorative surface and removes known background chrome. Kinds include window/panel, inset, input, button and track. `Control(frame, kind, owner, options)` handles buttons, tabs, checkboxes, dropdowns, inputs, sliders, scrollbars and icon cosmetics. Generic traversal preserves unknown button textures; stronger replacement requires a source-reviewed adapter, since normal textures can be content such as currency icons.
- `Text(fontString, role, preserveColor, owner)` preserves the native type size and text contents. Generic body styling retains an earlier explicit numeric/title role. Preserve semantic colors by default; neutral narrative black and known native control gold are the limited readability conversions. Never read or rewrite displayed text to infer its meaning.
- `Hide(region, owner)`, `SetSelected(control, boolean)`, `Watch(root, opts)` and `Restore(owner)` manage reviewed art, visual state, discovery and cleanup. Selection must come from a source-confirmed owner state; these helpers never click, select a tab, edit text or invoke a gameplay action. Selected/focused controls use near-black fill and the blue bottom marker from `Tokens.controls`.

Native discovery consumes `modules/WindowCatalog.lua`, generated from `docs/window-coverage.json`. Keep host, boundary, alias and scan-only metadata consistent with source evidence; run `python3 tools/window_catalog.py --check` after edits. The 172 catalog records include 129 native candidates, three native-recovery boundaries, 29 dedicated HUD records, eight Glue/front-end records, two media overlays and one embedded webpage. Registration is not native availability or proof of complete visual coverage. Model, map, item, spell, quest, quality and talent-state artwork remains with its owner. Embedded Help HTML, Glue screens and world-capture overlays stay outside the generic renderer.

## Preset status policy

`core/SetupStatus.lua` supplies the simple component model and required-HUD policy. Core profile application derives blockers itself; a button-only guard is insufficient. The required owners are FUF, Threat Plates, Bartender, Prat, SexyMap and Details plus addon-owned HUD placement. Optional unavailable owners remain visible as Skipped. Runtime failure is not healthy merely because an addon is loaded.

Snapshots record `setupPresetVersion`. Keep it stable for UI-only changes; increment it when the functional preset changes. Legacy or differently versioned snapshots cannot certify current settings as Applied. Current active profile paths, recorded values and runtime status must match; owner-added defaults are permitted. The main screen is a cached view with two primary actions and no OnUpdate/ticker. It never claims FPS or pixel parity. Detailed fields, technical reporting, performance and restore remain separate commands.
